A live run logs actual collection events before this block, including the nonce
sent in the JSON body of `POST /tee-report`. Verification rows have no per-stage
execution timestamps: they describe the completed Rust result. Successful labels
use ANSI green 32 in a terminal; entry numbers and event timestamps use dark gray.

After checking the live challenge deadline and the attestation endpoint over the
certificate-pinned TLS connection,
the application emits this final summary (illustrative):

```text
ATTESTATION SUMMARY
  Evidence: VERIFIED (reference_match)
  Confirmed IMA coverage: 47 entries; boot aggregate and kernel modules.
  Application: ADMITTED
Application/model files and GPU state are outside this measurement coverage.
```

For mismatched evidence the final result is `POLICY_MISMATCH` and `DENIED`.
For valid evidence with an expired nonce or wrong TLS peer, evidence remains
`VERIFIED` while the application is `DENIED`; credentials are not read.
